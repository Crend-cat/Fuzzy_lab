# Fuzzy Lab — гауссовские нечёткие величины

Программный комплекс для создания, отображения, арифметической обработки и кластеризации набора гауссовских нечётких величин.

## Быстрый запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установка:

```bash
python -m pip install --upgrade pip
python -m pip install -e ".[test]"
```

Запуск GUI:

```bash
fuzzy-lab
```

Либо:

```bash
python -m fuzzy_app.main
```

Тесты:

```bash
pytest
```

## Математическая модель

Одна нечёткая величина задаётся парой `GaussianFuzzyNumber(id, x0, sigma)` и плотностью

\[
f(x;x_0,\sigma)=\frac{1}{\sigma\sqrt{2\pi}}\exp\left(-\frac{(x-x_0)^2}{2\sigma^2}\right).
\]

Дополнительная нормировка плотности не производится. Уровень горизонтальной прямой по умолчанию равен `h = 0.7` и может изменяться в интерфейсе.

Для каждой величины определяется множество уровня `I_h = {x: f(x) >= h}`. Если `h` выше максимума плотности, величина исключается из текущего рабочего подмножества, но остаётся в исходном наборе.

## Генерация

Центры `x0_i` генерируются по формулам задания:

1. `omega_n = sqrt(12/n) * (sum(U_k) - n/2)`, где `U_k` независимы и равномерны на `[0, 1]`.
2. Одна из двух аппроксимаций для `eta`.
3. `x0_i = center_mean + center_std * eta_i`.

Знак первой поправки намеренно оставлен **минусом**, как в выданном задании.

Индивидуальная ширина `sigma_i` выбирается в одном из двух режимов:

- единая ширина для всех элементов;
- автоматическая независимая генерация `Uniform(sigma_min, sigma_max)`.

Равномерный закон для автоматической генерации ширин — проектное допущение, поскольку отдельный закон для `sigma_i` в задании не задан. На ограниченном интервале он не выделяет предпочтительные значения. Положительная нижняя граница гарантирует `sigma_i > 0`. Значения по умолчанию `0.15` и `0.45` выбраны так, чтобы при начальном `h = 0.7` все автоматически созданные функции имели непустое множество уровня. При изменении `h` набор пересчитывается без изменения исходных записей.

## Журналирование

После запуска приложение автоматически создаёт каталог `logs`:

- `logs/audit.sqlite3` — база SQLite со структурированными событиями;
- `logs/audit.jsonl` — полный читаемый JSONL-журнал;
- `logs/application.log` — краткая последовательность событий.

Журнал фиксирует генерацию и параметры всех созданных величин, добавление/редактирование/удаление, загрузку и сохранение наборов, изменение α, создание кластеров и сохранение результатов. Подробности и формат записей описаны в `docs/user_manual.md`.
